Análisis de requerimientos — SICRA

1. Descripción del problema

El Sistema de Control de Rescate y Adopción Animal (SICRA) tiene como objetivo facilitar la gestión de animales que necesitan rescate, 
atención veterinaria, recuperación y adopción. El sistema permitirá registrar casos, asignar responsables, actualizar estados y 
administrar solicitudes de adopción.

2. Actores principales

- Ciudadano o reportante: registra animales que necesitan ayuda e informa su ubicación y situación.
- Voluntario: atiende los casos asignados y registra las actividades realizadas.
- Veterinario: registra evaluaciones, diagnósticos y tratamientos.
- Administrador del refugio: supervisa los casos, asigna responsables y gestiona las adopciones.

3. Requerimientos funcionales

RF01: El sistema permitirá registrar nuevos casos de rescate.
RF02: El sistema permitirá clasificar a los animales por especie.
RF03: El sistema permitirá registrar la ubicación, fecha y descripción del caso.
RF04: El sistema permitirá asignar voluntarios y veterinarios a los casos.
RF05: El sistema permitirá actualizar el estado de cada caso.
RF06: El sistema permitirá registrar observaciones y tratamientos veterinarios.
RF07: El sistema notificará al personal correspondiente sobre nuevos casos y actualizaciones importantes.
RF08: El sistema permitirá gestionar solicitudes de adopción.
RF09: El sistema permitirá consultar el historial de cada caso.
RF10: El sistema permitirá administrar usuarios y sus permisos.

4. Requerimientos no funcionales

RNF01 — Mantenibilidad: el sistema tendrá una estructura modular que facilite su modificación.
RNF02 — Escalabilidad: permitirá incorporar nuevas especies y funcionalidades.
RNF03 — Seguridad: restringirá las operaciones según los roles y permisos de cada usuario.
RNF04 — Trazabilidad: conservará un historial de los cambios importantes realizados en los casos.
RNF05 — Reutilización: utilizará componentes que puedan compartirse entre distintas funcionalidades.
RNF06 — Integridad: validará los datos antes de guardarlos para reducir errores e inconsistencias.

5. Alcance del sistema

El sistema cubrirá el registro y seguimiento de rescates, la asignación de responsables, la atención veterinaria y la gestión de 
adopciones. La implementación de funcionalidades dependerá del alcance definido para el proyecto académico.
